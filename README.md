# CubeTex

Editor de texturas procedurais por nós com prévia 2D e 3D, projetos `.cubetex` e exportação de mapas PBR em PNG até 4096 × 4096.

## Abrir o editor

Baixe o repositório em **Code → Download ZIP**, extraia os arquivos e abra `index.html` no Chrome ou Edge. O editor funciona offline.

O projeto inicial mostra um cobre oxidado. Selecione um nó para ajustar seus parâmetros e arraste as conexões para combinar operadores. Em **Iluminação**, ajuste a direção e a intensidade da luz para gerar o bake. Use **Salvar projeto** para guardar o grafo editável e **Exportar mapa** para gerar uma textura.
